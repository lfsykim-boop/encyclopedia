# 밀가루 대백과

밀가루의 역사, 기능, 종류, 구조를 8개 대주제, 44개 표제어로 정리한 백과사전입니다. 초등학교 3학년이 읽고 이해할 수 있는 수준으로 설명했습니다.

- 웹사이트: https://lfsykim-boop.github.io/encyclopedia/
- 구성: 상단 30초 영상(밀가루로 빵 만들기), 총론(역사·기능·종류·밀알의 구조), 표제어 44개
- 기능: 검색, 대주제·가나다 초성 필터, 즐겨찾기, 읽어주기, 글자 크기 조절, 밤 모드

## 출처와 라이선스

- 본문은 위키백과(한국어·영어)의 다음 문서를 참고해 다시 썼습니다: 밀가루, 밀, 글루텐, 빵 / Flour, Wheat flour, Gluten, Wheat. 위키백과 문서는 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ko)으로 제공되므로, 이 저장소의 본문 내용도 같은 조건으로 공유합니다.
- 글꼴: 서울남산체(서울시 제공)를 웹폰트로 불러옵니다.
- 영상과 음악은 외부 파일 없이 코드(Canvas, Web Audio)로 만들었습니다.

## 구조

`index.html` 한 파일에 스타일, 데이터, 스크립트가 모두 들어 있어 별도 빌드 없이 열 수 있습니다.
